# APL Logistics AI Risk Prediction Dashboard

Machine Learning–based Late Delivery Risk Prediction System developed using Streamlit, Plotly, and Scikit-learn.

## Features
- Late delivery risk prediction
- AI-powered logistics insights
- Region & shipping mode analysis
- High-risk operational queue
- KPI dashboard
- Feature importance analysis
- Interactive filters
- Operational action recommendations

## Technologies Used
- Python
- Streamlit
- Plotly
- Pandas
- Scikit-learn
- Machine Learning
